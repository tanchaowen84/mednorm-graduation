# MEDNORM 医学疾病实体标准化研究资料

课题：大规模医学知识图谱的疾病实体标准化方法。公开研究版整理于2026-10-04，正式实验资料快照为2026-10-03。

输入为中文诊断名称，输出为固定ICD候选词表中的一个或多个标准疾病名称。正式方法包含字符/BGE召回、三种子精排、图谱画像、数量判断和Qwen结构信号。
